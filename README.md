# Финансовый трекер

Консольное приложение для отслеживания накоплений, с поддержкой SQLite и JSON.

---

##  Описание

Этот проект помогает отслеживать прогресс достижения финансовой цели.  
Ты можешь:
- Установить цель
- Добавлять пополнения
- Смотреть прогресс (в процентах)
- Хранить историю пополнений
- Смотреть сумму за месяц
- Очищать историю

Данные хранятся:
- В JSON (для быстрой загрузки цели и общей суммы)
- В SQLite (для истории пополнений)

---

##  Технологии

- Python 3
- SQLite3
- JSON
- datetime
